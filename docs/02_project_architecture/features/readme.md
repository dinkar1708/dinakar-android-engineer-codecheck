# Feature Documentation

This section contains detailed specifications for each feature implemented in the application.

---

## Feature List

### Core Features

1. **[Repository Search & List](./01_repository_search_list.md)**
   - GitHub repository search functionality
   - List view with search results
   - Sort and filter capabilities

2. **[Repository Detail](./02_repository_detail.md)**
   - Detailed repository information
   - Chrome Custom Tabs integration
   - Repository statistics display

3. **[Design System & Theming](./03_design_system_and_theming.md)**
   - Material 3 design tokens
   - Dark mode implementation
   - Color schemes and typography

4. **[Localization & Accessibility](./04_localization_and_accessibility.md)**
   - Bilingual support (English/Japanese)
   - Accessibility features (WCAG AA)
   - Screen reader compatibility

5. **[Settings & Preferences](./05_settings_and_preferences.md)**
   - User preferences management
   - Theme switching
   - Language selection

6. **[Splash Screen](./06_splash_screen.md)**
   - App branding and initialization
   - Animated entrance
   - Loading states

---

## Feature Development Process

Each feature follows this development lifecycle:

1. **Specification** → Detailed in these documents
2. **Architecture Design** → See ADRs and architecture guides
3. **Implementation** → Tracked in sprint roadmap
4. **Testing** → Unit, integration, and UI tests
5. **Documentation** → Code documentation and user guides
